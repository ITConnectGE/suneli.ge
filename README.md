# suneli.ge

Static mirror of suneli.ge (formerly DataLife Engine / PHP), served by GitHub Pages.

- `/` — Georgian skin, `/en/` — English skin
- `/produqcia/` and `/saintereso/` category listings were restored from the Wayback Machine
  (2021-04 snapshot), because the original server returned a MySQL error for them.
- Comments and likes use the Facebook plugin; the DLE comment form is non-functional.
